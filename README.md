# BAYHAN STUDIO — цифровая визитка

Статическая визитка Абдуллы Байхомбаева, основателя BAYHAN STUDIO. Сайт собирается в `dist` и публикуется на GitHub Pages без сервера.

## Локальный запуск

```bash
npm install
npm run dev
```

Сборка:

```bash
npm run build
npm run preview
```

## Что изменить вручную

Файл `src/config/site.ts`:

- `studioUrl` — полный адрес официального сайта BAYHAN STUDIO. Пока поле пустое, ссылка не показывается.
- `phone` — номер в международном формате, например `+998901234567`. Пока поле пустое, телефон не показывается и не попадает в контакт.
- `publicUrl` — постоянный адрес визитки. Сейчас: `https://apex3488.github.io/vizitka/`. Этот адрес используется в QR-коде и для NFC.

## Отдельный репозиторий и GitHub Pages

1. Создайте новый публичный репозиторий, например `bayhan-card`. Это может быть отдельный репозиторий, не связанный с другими проектами студии.
2. Загрузите в него эту папку. Ветка по умолчанию — `main`.
3. В репозитории откройте Settings → Pages → Build and deployment и выберите источник **GitHub Actions**.
4. Workflow `.github/workflows/deploy.yml` сам определит базовый путь:
   - проектный сайт: `https://USERNAME.github.io/REPOSITORY/`
   - пользовательский сайт `USERNAME.github.io`: `https://USERNAME.github.io/`
5. После успешного запуска Actions откройте вкладку Actions и адрес из шага Deploy.

Секреты, токены и платные сервисы не нужны. Домен покупать не требуется.

На NFC-метку запишите постоянный HTTPS-адрес опубликованной визитки. Его же показывает блок «Мгновенная связь» после публикации. Браузер сам метку не записывает: используйте совместимый телефон или NFC-приложение и выберите запись URL.
